마석 제작시간 계산기

사용법
입장권 입력
핫타임 미적용값·적용값 중 하나만 입력해도 됩니다. 입력한 값을 기준으로 다른 값이 자동 계산됩니다.
제작시간 계산
던전 숙련도와 현재 보유 재료, 보유 불멸·초월 마석을 입력하면 부족분을 기준으로 불멸·초월·절대 마석 1개 제작 예상시간을 계산합니다.
시간당 던전 입장권 획득량·던전 숙련도·현재 재료 보유량을 기준으로 불멸/초월/절대 마석 1개까지 걸리는 예상 시간을 계산합니다.

1. 입장권 / 던전 숙련도

160단계 · ×41.25
핫타임은 4배 기준입니다. 두 입장권 칸 중 하나만 입력하면 다른 칸이 자동 계산됩니다.
평일 24시간 획득량
-
일반 20시간 + 핫타임 4시간
주말 24시간 획득량
-
24시간 전체 핫타임
주간 평균 24시간 획득량
-
평일 5일 + 주말 2일 평균

2. 현재 재료 보유량

초월 제작은 보유 불멸을 최대 4개까지, 절대 제작은 보유 초월을 최대 4개까지 먼저 사용한 뒤 부족한 초월 제작에 보유 불멸을 자동 사용합니다.

3. 제작 예상시간

각 목표는 현재 보유 재료에서 각각 독립적으로 계산합니다. 초월 제작은 보유 불멸을 먼저 사용합니다. 절대 제작은 보유 초월을 먼저 사용하고, 부족한 초월 제작에 보유 불멸을 이어서 사용합니다. 불멸 마석 1개 결과에는 보유 상위 마석 수량을 적용하지 않습니다. 소탕 1회당 던전 입장권 2장을 사용하며 재료별 던전은 각각 따로 계산합니다.
