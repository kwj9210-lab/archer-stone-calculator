오행의 성역

사용방법 ▾

① 소탕 계산 · 클리어층과 필요한 재료 수량을 입력하면 소탕 횟수와 수련의 인장을 계산합니다.

② 보유·누적 계산 · 목표 재료, 최고층, 보유 재료를 입력하면 부족량을 계산합니다. 이미 받은 누적 보상은 중복 반영하지 마세요.

③ 층수 조회 · 층수를 입력하면 필요 관통·명중, 최고 체력, 1회 소탕 보상을 볼 수 있습니다.

예시 · 5,000층에서 재료 1종 5,000만 개가 필요하다면(보유 0개), 소탕 154회·수련의 인장 77만 개입니다.

현재 최대 5000층. 0.1.91 개편 기준이며 확인값은 100층 단위로 표시합니다.

소탕 계산

클리어층은 1~5000 직접 입력. 최초 입장과 1회 소탕은 해당 층수만큼 수련의 인장이 필요합니다. 계산기에서는 공지된 1,000층 초과 상향 보상식을 기본 적용하며, 필요 소탕횟수는 부족하지 않게 올림합니다. 실제 게임은 서버에서 전달된 보상 곡선 선택값을 사용하므로 획득량이 다를 수 있습니다. APK 기준 1회 소탕 요청은 최대 1,000회이므로 초과 횟수는 여러 번 나눠 진행해야 합니다.

보유·누적 + 소탕 계산

재료 1종 기준. 현재 보유량은 소탕 필요량에서 차감합니다. 누적 클리어 수량은 APK의 층별 보상식을 1층부터 최고층까지 합산한 계산값입니다. 최초 클리어의 실제 서버 지급 내역과 동일한지는 별도로 확인되지 않았습니다. 보유량에 이미 해당 보상이 포함됐다면 중복 반영하지 마세요.

층수 조회

층수는 1~5000 직접 입력합니다. 보스 HP는 일반적인 억·조 단위를 훨씬 넘어가므로, 실제 자릿수를 한글 억·만 단위의 10의 지수로 표시합니다. 영문 게임 단위와 같은 크기입니다.
