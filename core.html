1~20단계 재료 및 공격력 데이터

APK v0.2.10의 ARM64 네이티브 코드에서 복원한 1~20단계 데이터를 미리 입력했습니다. 현재 단계부터 목표 단계까지 필요한 재료와 공격력 증가량을 합산합니다. 숫자는 원본 정수이며 반올림하지 않았습니다.

단계천명석 소모성운석 소모초월핵 소모공격력 증가누적 공격력
단계별 수량은 APK v0.2.10의 libil2cpp.so에서 TranscendGroup, TranscendHeaven, TranscendNebula, TranscendCores, TranscendStepDigits, TranscendDigits 메서드를 역어셈블해 복원했습니다. 서버 응답과의 별도 교차검증은 아직 하지 않았습니다. 표의 값을 수정하면 해당 브라우저에 저장됩니다.

던전 입장권 계산

초월핵 제작에 부족한 재료를 기준으로 월신의 신전·천공의 용광로 소탕 횟수와 입장권을 계산합니다. 두 재료는 같은 던전에서 함께 얻으므로 던전별 소탕 횟수는 재료별 횟수를 더하지 않고 큰 값으로 계산합니다. 드랍 확률은 확인되지 않아 임의로 넣지 않았습니다.

원본 제작식 데이터 적용

20조각별 실제 게임 재료 이름과 수량이 담긴 JSON을 적용하면 재료 종류가 4개를 넘더라도 자동 계산합니다. 현재는 서버 제작식이 확보되지 않아 이 영역에 기본 수치를 넣지 않았습니다. 게임에서 확인되지 않은 JSON을 실제 레시피라고 표기하지 않습니다.
