단계별 소모량·공격력은 APK에 고정된 로컬 수치가 아니라 HeavenRelic021 응답의 TranscendHeaven / TranscendNebula / TranscendCores / TranscendStepDigits / TranscendDigits 필드로 전달되는 서버 데이터임을 확인했습니다. 실제 수치를 임의로 채우지 않았습니다.

게임 데이터 일괄 불러오기

게임 서버 응답 JSON을 붙여넣으면 초월 관련 숫자 배열을 찾아 20단계 표에 반영합니다. 필드별 배열을 직접 지정할 수 있습니다. 배열이 21개 이상이면 첫 값은 0단계로 보고 1~20단계를 가져옵니다.

JSON 분석 후 발견한 필드와 배열 길이를 확인할 수 있습니다. 적용 전에는 기존 단계 데이터가 변경되지 않습니다.
