던전 입장권 계산

백금괴·성철괴는 실제 1회 획득량을 입력하세요. 월광수·별의 핵은 드랍 확률을 반영한 평균 예상 획득량(확정값 아님)으로 계산합니다.

고정 재료 기본 입력값은 숙련도 15,168의 실제 화면 기준입니다. 숙련도를 변경하면 고정 재료의 실제 획득량도 직접 갱신하세요. 고정 재료에는 배율을 다시 곱하지 않습니다.

원본 제작식 데이터 적용

20조각별 실제 게임 재료 이름과 수량이 담긴 JSON을 적용하면 재료 종류가 4개를 넘더라도 자동 계산합니다. 현재는 서버 제작식이 확보되지 않아 이 영역에 기본 수치를 넣지 않았습니다. 게임에서 확인되지 않은 JSON을 실제 레시피라고 표기하지 않습니다.
