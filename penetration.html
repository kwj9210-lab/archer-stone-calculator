관통 Total

사용방법 ▾

① 기본값 · 기본 능력치 관통은 직접 입력합니다. 갑파 및 정밀술은 레벨 입력값에서 관통 증가량을 계산한 뒤 합산합니다. 갑파 중간 레벨은 임시 계산입니다.

② 정령·코스튬 · 정령 관통과 보유 코스튬 개수, 장착 효과를 입력합니다.

③ 각인석 · 마석·경화석·생명석의 등급별 장착 수량을 입력합니다. 각 종류는 기본 최대 11칸입니다.

④ 장갑 · 3~1등급 장갑을 등급과 이름으로 선택합니다.

⑤ 오행 개방 · 완료 단계의 누적 관통을 합산합니다.

⑥ 결과 · 최종 관통과 각 항목의 관통 합계를 확인하고 초월의 탑으로 전달합니다.

예시 · 마석 전설 2개는 104 × 2 = 관통 208를 더합니다.

궁수키우기 RPG · 기본 능력치, 정밀술, 정령, 코스튬, 각인석, 장갑, 오행 개방 관통 합산

01 · 기본 관통

능력치 관통은 수치를 직접 입력하고, 갑파·정밀술은 강화 레벨(1~300)을 입력하면 관통 증가량을 자동 계산합니다. 최종 관통에는 강화 레벨 자체가 아닌 계산된 관통만 합산합니다. Lv.300은 각각 +3,570입니다. 갑파 중간 레벨은 별도의 게임 공식 확인 전까지 정밀술 계산식을 임시 적용합니다.

02 · 정령

0~100단계는 기존 게임 확인값으로 자동 계산합니다. 101~150단계는 기존 증가식을 연장한 예상값입니다. 실제 게임의 관통이 다르면 위의 관통 입력칸에서 직접 수정하세요.

03 · 코스튬 관통

보유 개수를 입력하면 관통 증가량만 합산합니다. 캐시 최대 +750, 월드보스 관통형 최대 +440, 마일리지 갑주 최대 +630, 할로윈 코스튬 최대 +1,200입니다. 관통이 없는 코스튬은 제외했습니다.

04 · 각인석 장착 수량

마석·경화석·생명석은 각각 최대 11개를 장착할 수 있습니다. 같은 등급 여러 개도 입력할 수 있습니다. 마석·경화석·생명석의 13개 등급 관통 수치를 최신 게임 스크린샷 기준으로 반영했습니다. 장착 슬롯 11칸은 기존 참고자료 기준입니다.
미적용 · 종류나 등급을 선택하면 자동으로 적용됩니다.
자유 각인 최대 2칸 · 각 슬롯에서 선택한 각인석 1개씩의 관통을 합산합니다. 초월·절대·혼돈급도 선택할 수 있습니다.

05-2 · 신발 도감 관통 (9~1등급)
등급마다 5세트, 총 45세트입니다. 완성한 세트에만 해당 등급의 관통 보너스를 적용하며, 신발 장착 관통과 별도로 합산합니다.

신발 도감 완성 현황 · 45세트 (클릭해서 펼치기)

검증 구분: 능력치 강화 관통은 게임 화면에 표시된 수치를 직접 입력합니다. 요청하신 입력 상한 MAX 400을 적용했습니다. 오행 개방은 기존 APK 분석식, 정령·정밀술은 APK 네이티브 코드, 코스튬·기존 각인석은 첨부 참고자료, 절대·혼돈급은 게임 아이템 설명 이미지 기반입니다. 패시브·일부 코스튬·각인석 장착 슬롯 MAX와 추가 효과 조건은 별도 확인이 필요합니다. 입력값은 현재 브라우저에 자동 저장되고 다음 방문 시 복원됩니다. 다른 기기나 브라우저와는 공유되지 않으며, 입력 초기화 시 저장값도 삭제합니다.
APK 데이터 검증 범위 / MAX값 확인

능력치 강화 관통 · 게임 ‘능력치 강화 → 관통’에 표시된 값을 직접 입력합니다. 이전의 활 등급별 50~360 상한은 서로 다른 능력치 규칙이므로 여기에 적용하지 않습니다. 이번 계산기 입력 상한은 요청하신 MAX 400입니다.

정령 확장 · 게임 v0.2.3에서 최대 150단계로 확장. 0~100단계는 게임 확인값(100단계 +5,110), 101~150단계는 기존 증가식 연장 예상값(150단계 +7,685)을 적용합니다. 실제 게임 기본 관통값을 입력하면 그 값을 우선 합산합니다.

APK 0.1.91 확인 · 초월 정밀술 0~300레벨, 관통 최대 +3,570. 100레벨에서는 +273. 오행 개방 0~100단계, 완료 보상 누적 관통 최대 +15,000.

첨부 참고값 · 갑파 레벨 입력 상한 300 (Lv.300 관통 +3,570은 게임 화면 확인, 중간 레벨은 정밀술 식 임시 적용), 코스튬 개수 10/24(관통형 22 + 기존 방어형 2)/18/9(캐시 신규 4종, 월드보스 신규 12종 추가 반영; 관통 증가량은 기존과 동일), 기존 각인석 등급 수치 및 11칸+자유 2칸. 초월·절대·혼돈 관통은 사용자 게임 스크린샷을 반영했습니다. 슬롯 MAX와 조건의 APK 전체 대조는 끝나지 않았습니다.
