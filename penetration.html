관통 Total

사용방법 ▾

① 기본값 · ‘능력치 강화’의 관통 수치를 그대로 입력합니다(예: 370). 패시브를 더하고 정밀술은 레벨로 계산할 수 있습니다.

② 정령·코스튬 · 정령 관통과 보유 코스튬 개수, 장착 효과를 입력합니다.

③ 각인석 · 마석·경화석·생명석의 등급별 장착 수량을 입력합니다. 각 종류는 기본 최대 11칸입니다.

④ 오행 개방 · 완료 단계의 누적 관통을 합산하고 성역 도전층 필요 관통을 확인합니다.

⑤ 결과 · 스킬·추가 관통을 반영해 게임 표시 관통과 비교할 수 있습니다.

예시 · 마석 전설 2개는 52 × 2 = 관통 104를 더합니다.

궁수키우기 RPG · 기본 능력치, 정밀술, 정령, 코스튬, 각인석, 오행 개방, 스킬 관통 합산

01 · 기본 관통

사진의 ‘능력치 강화 → 관통’에 표시되는 수치를 그대로 입력하세요. 예: 관통 370 → +370 합산. 이 항목의 실제 강화 상한은 확인되지 않아 임의 MAX 제한을 두지 않았습니다. 정밀술은 별도 강화 효과로 Lv300 최대 +3,570이며, 패시브 450은 첨부 참고값입니다.

02 · 정령

APK 0.1.91 정령 Flat 함수: 1~100단계 자동 계산 · 3단계 +22 · 100단계 +1,022. FlatForCombat의 조건부 ×5 효과는 실제 적용될 때만 선택하세요.

03 · 코스튬 보유 및 장착 효과

코스튬 개수·개당 관통은 첨부 시뮬레이터 수치입니다. 이번 APK 조사에서는 전체 구매 상한까지 독립 확인하지 못했습니다.
캐시 코스튬 · 개당 +3최대 6개
월드보스 코스튬 · 개당 +10최대 7개
마일리지 코스튬 · 개당 +3최대 12개
다이아 코스튬 · 개당 +3최대 3개

04 · 각인석 장착 수량

마석·경화석·생명석은 각각 최대 11개를 장착할 수 있습니다. 같은 등급 여러 개도 입력 가능합니다. 11칸과 등급별 관통은 첨부 참고자료 수치이며 APK 최신 제한 전체 검증값은 아닙니다.
자유 각인 슬롯 1개에 선택한 각인석 1개의 관통을 추가합니다.

05 · 오행 개방 누적 관통

+0
오행 개방 완료 보상만 합산합니다. 현재 강화 중인 단계가 완료되기 전에는 단계 완료 관통을 더하지 않습니다. 100단계 완료 시 +15,000입니다.

06 · 오행의 성역

미선택
성역은 강화 재료 획득처이며, 층수나 요구 관통을 획득 관통에 더하지 않습니다.

07 · 스킬·추가 관통

APK에 스킬의 PierceFlat 효과 항목이 있습니다. 게임에서 적용된 수치만 입력하고 기존 능력치·정밀술과 중복되지 않도록 확인하세요.

검증 구분: 능력치 강화 관통은 게임 화면에 표시된 수치를 직접 입력합니다. 이 강화 항목의 MAX는 아직 확인되지 않았습니다. 오행 개방은 기존 APK 분석식, 정령·정밀술은 APK 네이티브 코드, 코스튬·각인석은 첨부 참고자료 기반입니다. 패시브·코스튬·각인석의 MAX와 추가 효과 조건은 별도 확인이 필요합니다. 입력은 브라우저에 자동 저장됩니다.
APK 데이터 검증 범위 / MAX값 확인

능력치 강화 관통 · 게임 ‘능력치 강화 → 관통’에 표시된 값(사진 예시 370)을 직접 입력합니다. 이전의 활 등급별 50~360 상한은 서로 다른 능력치 규칙이므로 여기에 적용하지 않습니다. 실제 능력치 강화 MAX는 미확인입니다.

APK 0.1.91 확인 · 정령 0~100단계 기본 관통 최대 +1,022. 전투 조건 플래그 활성 시 정령 관통 ×5.

APK 0.1.91 확인 · 초월 정밀술 0~300레벨, 관통 최대 +3,570. 100레벨에서는 +273. 오행 개방 0~100단계, 완료 보상 누적 관통 최대 +15,000.

성역 별도 처리 · 오행의 성역은 오행 개방 재료를 얻는 장소이며, 필요 관통은 조회만 합니다. 직접 획득 관통으로 더하지 않습니다.

첨부 참고값 · 갑파 패시브 최대 450, 코스튬 개수 6/7/12/3, 각인석 등급별 수치 및 11칸+자유 1칸. 이 항목들의 모든 MAX와 조건은 APK와의 완전 대조가 끝나지 않았습니다.

직접 확인 입력 · 스킬 PierceFlat 및 기타 효과는 게임 실제 적용값을 입력합니다. 게임 표시 관통과 계산값을 비교해 빠진 효과와 중복 합산을 확인할 수 있습니다.
